# Zos Pad Documentation & Demo

Welcome to **Zos Pad**, a lightweight, standalone Notepad-style text editor with embedded multi-language highlighting for `.zos` files.

## Arabic and English Mixed Support
هذا النص باللغة العربية مع كلمات English words للتأكد من المحاذاة والاتجاه الصحيح.

- [x] Feature 1: Plaintext by default
- [x] Feature 2: Monaco Monarch embedded code blocks
- [x] Feature 3: GitHub-style Markdown Preview
- [ ] Feature 4: Testing task lists

| Language | Extension | Highlighting Mode |
| :--- | :--- | :--- |
| Zos Document | `.zos` | Multi-language embedded |
| Python | `.py` | Plain text |
| C# | `.cs` | Plain text |
| Markdown | `.md` | Plain text (Edit) / GitHub (Preview) |
